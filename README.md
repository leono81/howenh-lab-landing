# Howenh Labs Landing Page

Landing page para Howenh Labs - Empresa de desarrollo de software y automatización con IA desde Tierra del Fuego, Argentina.

## 🚀 Stack

- **HTML5** + **CSS3** (Tailwind CDN)
- **JavaScript** (vanilla)
- **Google Fonts**: Space Grotesk, Noto Sans
- **Material Symbols** icons

## 🎨 Diseño

- Dark mode con glassmorphism
- Color primario: `#ffb200` (dorado)
- Responsivo (desktop + mobile)

## 🛠️ Desarrollo Local

Simplemente abre `index.html` en tu navegador, o usa un servidor local:

```bash
# Con Python
python -m http.server 8080

# Con Node.js
npx serve
```

## 📦 Deploy

Este proyecto está preparado para deploy como sitio estático en **Coolify**.

## 📍 Ubicación
